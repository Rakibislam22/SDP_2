# ChronoMate

**ChronoMate** is an all-in-one productivity desktop application built using Python and CustomTkinter. It combines time management tools with essential everyday utilities—designed for students, professionals, and productivity enthusiasts.

---

## 🛠 Features

### 🕒 Time Management
- **World Clock** – View multiple time zones.
- **Stopwatch** – With lap timing functionality.
- **Multiple Timers** – Customizable with presets and labels.
- **Alarm Clock** – Set alarms with custom sounds.

### 🌦 Utility Widgets
- **Weather Widget** – Live weather updates using the OpenWeatherMap API.

### 📱 Converters & Calculators
- **Calculator** – Standard and advanced expression handling (e.g., `234-5%`).
- **Currency Converter** – Converts real-time currency rates via API.
- **Unit Converter** – Convert length, weight, temperature, etc.

### 🎵 Media Players
- **Audio Player** – Lightweight music player with play/pause, loop.
- **Video Player** – Embedded VLC-powered player with queue, seek, fullscreen support.

### 🗓️ Calendar & To-Do
- **Calendar** – Monthly view.
- **To-Do List** – Add, edit, and delete daily tasks.

### 🎮 Games
- **Rock-Paper-Scissors**
- **Tic-Tac-Toe**
